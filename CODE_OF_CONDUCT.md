# Code of Conduct

nullpii follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful and constructive, assume good faith, and keep discussion about the work. Harassment, personal attacks and publishing other people's private information are not accepted, which matters doubly in a project about personal data.

## Reporting

Report unacceptable behaviour privately to the maintainers through a [private security advisory](https://github.com/lBroth/nullpii/security/advisories/new) (it reaches the maintainers only, and is not limited to security issues). Reports are handled confidentially. Maintainers may remove comments, commits or issues that break this code, and may ban a contributor temporarily or permanently, following the Covenant's enforcement guidelines.
