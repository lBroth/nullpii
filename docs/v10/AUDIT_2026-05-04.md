## Critical Findings (act immediately)

### F10 — `_remap_span` off-by-one truncates trailing char (`adapters.py:2581-2583`)

```python
# CURRENT (BUG)
if norm_end >= len(norm_to_orig): norm_end = len(norm_to_orig) - 1
return norm_to_orig[norm_start], norm_to_orig[norm_end]

# FIX
def _remap_span(norm_start, norm_end, norm_to_orig):
    max_idx = len(norm_to_orig) - 1
    ns = max(0, min(norm_start, max_idx))
    ne = max(0, min(norm_end, max_idx))
    return norm_to_orig[ns], norm_to_orig[ne]
```

Off-by-one when model predicts `end == len(normalized)`. Trailing `m` of `.com` / `7` of phone leaks in chunked path.

**Test**: input with one ZWSP appended; model predicts span `(0, 17)` over normalized; expected restore covers full original `johndoe@gmail.com`; current returns `text[0:16]` — leaks `m`.

### F01/F02 — `_SPACED_PII_RE` threshold + mid-word match (`adapters.py:2484`)

```python
# CURRENT
_SPACED_PII_RE = re.compile(r"(?:[\w@.+\-]\s+){5,}[\w@.+\-]")

# FIX
_SPACED_PII_RE = re.compile(r"(?<!\w)(?:[\w@.+\-:/]\s+){3,}[\w@.+\-:/]")
# Post-check: ≥4 digits OR (≥1 @ + ≥1 letter)
```

Threshold of `{5,}` lets `+ 4 9 3 0` (4 pairs) silently pass. Mid-word despace mangles `Mary J. Doe age 4 7` → `yJ.De47`.

**Test**: `+ 4 9 1 7 6` despaces; `Mary J. Doe age 47` does NOT.

## Other High Findings

### F03 — HTML entity decode breaks email anchor

`j&#x40;ohn@example.com` decodes to double-`@`. Fix: only decode entities for non-anchor chars in identifier context.

### F04 — Percent decode offset map collapses

All 3 decoded chars share orig idx — `_remap_span` returns `(0, 3)` only. Fix: store `(orig_start, orig_end)` interval per decoded char.

### F06 — IPv4/IPv6/MAC over-match

- IPv4 matches `version 3.14.15.92`. Use bounded octet pattern.
- IPv6 matches illegal `dead:beef::1::5`. Validate via `ipaddress.ip_address()`.
- MAC matches 7-octet bus addresses. Add `(?<![:0-9A-Fa-f])` lookbehind.

### F07 — BTC Legacy without checksum

`Order ID: 1A2B3C4D5E6F7G8H9J1K2L3M4N` matches. Add base58check verification post-match.

### F08 — URL whitelist + greedy regex leak embedded URLs

`https://github.com/?next=https://shadowco.test.private/secret` — outer `github.com` whitelisted, inner URL leaks. Fix: split on `https?://` re-finditer in matched span.

### F11 — Primary ensemble drops higher-priority regex

CF/IBAN regex match overlapping with model `private_person` span gets dropped. Fix: switch default to `score_ranked` strategy (already exists, line 1947).

### F12 — Trim chars ASCII-only

`’O’Brien’` typographic apostrophes not stripped. Fix: extend `trim_chars` with `«»‹›‘’“”„‚`.

### F15 — `_ENV_VAR` false matches

`MY_BIRTHDAY=1990-01-01` triggers env-block route. YAML `KEY:` not matched. Fix: drop matches whose value is date/email; allow `:` and lowercase context.

### F21 — TS escape/unescape mutates user text

`regex: [\[abc]` round-trip drops backslash. Fix: use sentinel that can't collide with user input.

### F23 — `_SPACED_PII_RE` O(N²) on whitespace-rich input

100 KB of `a a a a …` → 5s scan in CPython. Fix: pre-screen before match call, OR finditer once outside loop.

### F25 — TS library lacks Python research's defenses (✅ CLOSED 2026-05-05)

**Closed via `src/normalize.ts`, `src/recognizers.ts`, `src/defaults.ts`**:

- **Adversarial preprocessor**: `src/normalize.ts` ports `_normalize_for_detection` end-to-end. Applies in order: whitespace-obfuscated PII despace (gated on ≥4 digits OR ≥1 `@` + ≥1 letter to avoid prose mangling), URL %XX decode (with email-anchor guard), HTML numeric entity decode (with email-anchor guard), zero-width / soft-hyphen / word-joiner strip, per-char NFKC, per-char ASCII transliteration via `any-ascii` (ISC license, npm package). `remapSpan(start, end, normToOrig)` mirrors Python `_remap_span` with strict `min(idx, max_idx)` clamp (F10-equivalent in TS). Input length cap of 1 MB matches Python `_REGEX_INPUT_MAX_BYTES`. Adversarial F1 lift expected to mirror Python: adv-unicode 0.466 → 0.936, adv-whitespace 0.106 → 0.393, adv-typo to 0.940.
- **Pipeline integration** (`src/nullpii.ts`): `sanitize()` now feeds `normalized` to the tokenizer and remaps ML span offsets back to `escaped` text via `remapSpan` before the recognizer post-pass. Recognizers run on `escaped` (un-normalised) so their literal anchors line up with original character forms.
- **`DEFAULT_RECOGNIZERS` regex pack expansion**: 10 → 74 patterns (parity with Python `DEFAULT_REGEX_PATTERNS`). Coverage now spans:
  - **AWS** (access keys + Bedrock long-lived)
  - **GitHub** (ghp_/ghs_/gho_/ghu_/ghr_ + github_pat_)
  - **OpenAI / Anthropic** (sk-, sk-ant-, sk-ant-admin01-, sk-ant-api03-)
  - **Stripe / 1Password / Adobe / Age / Airtable / Alibaba**
  - **Artifactory / Atlassian** (AKCp, cmVmd, ATATT3)
  - **Slack / GitLab / SendGrid / Twilio / NPM / PyPI / HF / Mailchimp / Notion / Linear**
  - **PEM / JWT** (`{8,2048}` per segment, F22-bounded)
  - **Google / Discord / Telegram / Mailgun / Mapbox / Square / PayPal / Heroku**
  - **Account-number**: IBAN (F05-fixed `\s?` for NBSP), SSN, BTC (3 variants), ETH, UUID v4, MAC (F06 boundary-anchored), IPv4 (F06 octet-bounded), IPv6 (full + compressed)
  - **National IDs**: Spanish DNI, Brazilian CPF, US passport, US EIN, Italian Codice Fiscale (F19)
  - **Phone**: international `+CC`, domestic IT/FR/ES (F09 context-anchored to `tel:` / `telefono:` / etc.)
- **`filterNeverPii()`** in `src/recognizers.ts` mirrors Python `_is_never_pii`:
  - NANP fictional `555-01XX` phones
  - RFC1918 private IP ranges (`10.x`, `192.168.x`, `172.16-31.x`)
  - RFC 6761 reserved TLDs (`example.com/net/org`, `test`, `invalid`, `localhost`, `local`) on `private_url` + `private_email`
  - Null UUID + zero MAC
- **F22 ReDoS guard** in TS: all `{N,}` patterns bounded to `{N,255}` (or `{N,2048}` for JWT/1Password); 1 MB input cap on `runRecognizers()` short-circuits oversized inputs.

**Tests**: 157 pass / 8 skipped. New `test/normalize.test.ts` covers ASCII passthrough, zero-width strip, Cyrillic homoglyph transliteration, URL %XX decode (with email-anchor guard), HTML entity decode, despace gating (digit count + `@`+alpha), 1 MB cap, span remap (F10-equivalent clamp).
