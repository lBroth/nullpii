# nullpii-bench

Multilingual PII evaluation dataset for `nullpii` and other PII
detection tools. **271 samples, 680 PII spans, 5 locales, Apache 2.0.**

## Schema

Each line in `nullpii-bench.jsonl` is one sample:

```jsonc
{
  "id": "bundled-it-0023",
  "locale": "it",
  "subset": "bundled",                            // bundled | adversarial | long-prompts
  "text": "Inoltrare a Maria Rossi (maria.rossi@example.it) entro venerdì.",
  "spans": [
    { "label": "private_person", "start": 11, "end": 22 },
    { "label": "private_email",  "start": 24, "end": 47 }
  ]
}
```

Spans use the 8 nullpii PII categories:

- `private_person`
- `private_email`
- `private_phone`
- `private_address`
- `private_date`
- `private_url`
- `account_number`
- `secret`

## Subsets

| Subset         | Samples | Description                                                                                |
| -------------- | ------: | ------------------------------------------------------------------------------------------ |
| `bundled`      |     202 | Dev-style prompts (PR reviews, deploy logs, RFCs, customer support) across 5 locales.      |
| `adversarial`  |       7 | Decoy strings that look like PII but aren't — false-positive stress test.                  |
| `long-prompts` |      62 | English long-form prompts (~3k chars each) with PII positioned past the 512-token mark.    |
|                |         | Stress test for chunking; bare HF / GLiNER / piiranha all score ~0 on this subset.         |

## Locale distribution

| Locale | Samples |
| ------ | ------: |
| `en`   |     131 (62 bundled + 7 adversarial + 62 long-prompts) |
| `it`   |      40 |
| `de`   |      34 |
| `fr`   |      33 |
| `es`   |      33 |

## Construction

`bundled` per-locale prompts are generated from
`<locale>-templates.txt` via `datasets/build.py`. Templates use
`{{label|text}}` markup; the builder strips the markup and emits
character-level spans.

`long-prompts-en` is built from `en-baseline.jsonl` by prepending
~2 KB of dev-flavored filler (CI logs, stack traces, dependency
audits) before each sample, pushing PII past token 512. Generated by
`scripts/build_long_prompts.py`.

`adversarial.jsonl` is hand-curated decoys.

To regenerate the merged file:

```bash
cd packages/eval
python3 datasets/build_nullpii_bench.py
```

## Eval framework support

The merged file is loadable directly:

```python
from datasets import Dataset
ds = Dataset.from_json("packages/eval/datasets/nullpii-bench.jsonl")

# Filter by subset / locale
bundled_it = ds.filter(lambda r: r["subset"] == "bundled" and r["locale"] == "it")
long_en   = ds.filter(lambda r: r["subset"] == "long-prompts")
```

Add new dev-style prompts to `<locale>-templates.txt` using
`{{label|text}}` markup, then run `python3 datasets/build.py` and
`python3 datasets/build_nullpii_bench.py`. PRs welcome — especially
