Quick architecture sanity check.

We're building a referral system where the referrer's email is
embedded in a signed URL that the referee clicks. The current draft:

```
https://acme.com/r/{token}
```

where `{token}` is a JWT containing `{ ref_email, exp }`, signed
with HS256 using a shared secret in our config service. Example
payload after base64-decoding the middle segment:

```json
{
  "ref_email": "{{private_email|early.adopter@gmail.com}}",
  "ref_name":  "{{private_person|Beatrice Wagner}}",
  "exp": 1737936000

```

1. JWTs are URL-safe but not opaque — anyone who clicks the link
