# presidio-analyzer run per its multilingual docs, one spaCy NER model per
# language, plus what scripts/bench_full.py needs to import and load datasets.
# The spaCy models are pinned wheels (release 3.8.0, compatible with spaCy
# 3.8.x) with their SHA-256, so pip verifies each download. About 8 GB.
#
# Create it (tested with Python 3.12):
#   python3.12 -m venv ~/.cache/nullpii-eval/venv-presidio
#   ~/.cache/nullpii-eval/venv-presidio/bin/pip install -r packages/eval/requirements-presidio.txt
#   ~/.cache/nullpii-eval/venv-presidio/bin/pip install -e packages/eval --no-deps
# Run the bench with that venv's python:
#   ~/.cache/nullpii-eval/venv-presidio/bin/python packages/eval/scripts/bench_full.py --tools presidio ...
